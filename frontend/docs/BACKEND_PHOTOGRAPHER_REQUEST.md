# طلب مصور من المالك — الحل: الأدمن يعيّن المصور

## المشكلة
- المالك بيطلب "مصور معتمد من رواف" من معالج إضافة العقار ومن صفحة العقار.
- الطلب هو `POST /host/tasks` بنوع `PHOTO_SHOOT` ومن غير `assigneeId`، فبيرجع:
  ```json
  { "code": "INVALID_ASSIGNEE", "message": "A photo shoot needs a photographer" }
  ```
- المالك مش المفروض يختار المصور، ومفيش endpoint يعرّفه المصورين أصلاً.

## المطلوب
1. **`POST /host/tasks` يقبل `PHOTO_SHOOT` من غير `assigneeId`** (للمالك والمشغّل):
   - المهمة تتعمل `TODO` و`assignee: null`.
   - باقي أنواع المهام تفضل زي ما هي.
2. **فلتر للمهام اللي مش متعيّن لها حد:** `GET /host/tasks?type=PHOTO_SHOOT&status=TODO&unassigned=true`. الأدمن بيستخدمه عشان يجيب الطلبات المستنية مصور.
3. **التعيين** بـ `PATCH /host/tasks/:id { "assigneeId": "..." }`:
   - الـ endpoint ده موجود فعلاً.
   - المطلوب نتأكد إن الأدمن يقدر يستخدمه على أي عقار.
   - ولو المهمة نوعها `PHOTO_SHOOT`، الـ `assigneeId` لازم يكون مستخدم دوره `PHOTOGRAPHER` ونشط، وإلا يرجع `INVALID_ASSIGNEE`.
4. **الإشعارات:**
   - طلب تصوير جديد ← إشعار للأدمن، template جديد مثلاً `shoot.requested.admin`.
   - تعيين المصور ← `task.assigned.staff` للمصور، وإشعار للمالك إن الجلسة اتحدد لها مصور.
5. **عند المالك:** مهمة التصوير من غير مصور تظهر في المهام كـ "بانتظار تعيين مصور" (`assignee: null`). مفيش تعديل مطلوب هنا، بس نتأكد إن `GET /host/tasks` بيرجعها.

## من ناحية الفرونت
- هنعمل قايمة "طلبات تصوير بانتظار مصور" في بوابة الأدمن (شاشة فحص جودة الصور).
- المصورين بيتجابوا من `GET /admin/users?role=PHOTOGRAPHER`، وده شغال فعلاً.
- الأدمن يعيّن بـ `PATCH /host/tasks/:id`.

ابعتولنا لما يكون جاهز على `192.168.1.14`.
